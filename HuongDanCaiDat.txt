============ HƯỚNG DẪN CÀI ĐẶT ============

1. CÔNG CỤ & MÔI TRƯỜNG PHÁT TRIỂN:
- Ngôn ngữ: Python bản >= 3.10
- Docker & Docker Compose (cần thiết để chạy Database TimescaleDB)
- Trình duyệt ảo Chromium (do Playwright quản lý tự động, không yêu cầu cài sẵn trình duyệt ngoài)
- (LƯU Ý: Thư mục nộp bài này không đính kèm các thư viện để tối ưu dung lượng. Vui lòng cài đặt thư viện theo hướng dẫn dưới đây).

2. CÁCH CÀI ĐẶT MÔI TRƯỜNG VÀ THƯ VIỆN:
Bước 1: Mở Terminal (Command Prompt / PowerShell) tại thư mục gốc của project (nơi chứa file này).

Bước 2: Tạo môi trường ảo (Virtual Environment)
- Windows: 
    python -m venv .venv
    .\.venv\Scripts\activate
- macOS / Linux: 
    python3 -m venv .venv
    source .venv/bin/activate

Bước 3: Cài đặt các thư viện cần thiết
- Sau khi đã vào môi trường ảo (thấy chữ `(.venv)` hiện ở đầu dòng command), chạy lệnh:
    pip install -r requirements.txt
    pip install -e .

Bước 4: Cài đặt trình duyệt ảo (Playwright)
- Sau khi tải xong thư viện ở bước 3, chạy lệnh sau để tải Chromium:
    playwright install chromium

Bước 5: Tải spacy model (dùng cho bóc tách skill NLP)
    python -m spacy download en_core_web_sm

3. CÁC THIẾT LẬP KẾT NỐI:
- Kịch bản Crawler đã được thiết lập. Hãy copy file `example.env` thành một file mới có tên là `.env` đặt ngay tại thư mục chứa file `example.env`. 
(Trong file `.env` đã có sẵn thông số kết nối Database mặc định).
