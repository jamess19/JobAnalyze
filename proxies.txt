# Proxy List for Scrapy Spider
# ================================
# Add one proxy per line in the format:
#   http://ip:port
#   https://ip:port
#   http://user:pass@ip:port
#   socks5://ip:port
#
# Lines starting with # are ignored.
# If this file is empty or missing, the spider will run without proxies.
#
# Example:
# http://103.155.217.1:41317
# https://203.30.189.46:80
# http://user:password@192.168.1.1:8080
